Settings

Uses an OpenAI API key and separate API billing. A ChatGPT subscription alone does not provide an API key.

Also saves submitted questions and partial answers with encryption. After an interruption, saved text reappears for review; retrying sends a new request. Images and unsent drafts are not saved.

Close requests hide the overlay. Normal external Quit requests are blocked. Quit from this app asks for confirmation. Windows shutdown and apps that terminate processes can still stop it.

Capture protection covers this overlay and its Settings. Capture methods vary; check your meeting's sharing preview before relying on it. File picker dialogs may still appear.

Text and attached images are sent directly to your selected AI provider when you ask. Images stay in memory and are not saved with your conversation. Follow-ups can include recent images in this session.

Applies immediately. Turning this off pauses reopening until the next launch. Quit stops the app and automatic reopening.

New chat saves the current conversation here. Chats restore after reopening when conversation history is enabled. Images remain in memory only.
